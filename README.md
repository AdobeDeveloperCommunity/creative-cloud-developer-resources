## UXP Plugins

- [Bolt UXP](https://hyperbrew.co/resources/bolt-uxp/) - A lightning-fast framework for building Adobe UXP Plugins in React, Svelte, or Vue built on Vite + TypeScript + Sass
- [UXP Validator for VS Code by Jarda](https://github.com/jardicc/vscode-uxp-validator) - CSS Style Validator for UXP Plugins
- [Alchemist by Jarda for BatchPlay in Photoshop UXP](https://github.com/jardicc/alchemist) - Toolkit for Capturing Photoshop BatchPlay commands

## ScriptUI

- [Extender by Klustre](https://github.com/Klustre/extender) - About A modern starter for writing Adobe Extendscript
- [Extender by Motion Developer](https://github.com/motiondeveloper/adobe-script-starter) - Simple starter for writing Adobe JSX scripts in TypeScript, transpiled to ES3 with SWC.
- [ScriptUI Dialog Builder by Joonas](https://scriptui.joonas.me/) - Build your Script UI with easy drag and drop elements

## CEP Extensions

- [Adobe Photoshop HTML Panels - by Davide Barranca](https://www.ps-scripting.com/html-panels.html) - Complete guide on building CEP Extensions for Adobe apps
- [Premiere on Script by Eli Portell](https://premiereonscript.com/) - a blog of many useful articles on
